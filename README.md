# HOC Terminal for Windows and Mac

The desktop app for the [HOC Terminal](https://terminal.hocapital.net) by [HO Capital](https://hocapital.net).
Members download it from the **Downloads** page in the terminal.

- **Windows:** download the Setup `.exe` and open it. If Windows shows "Windows protected your PC", click *More info* → *Run anyway*.
- **Mac:** open the `.dmg` and drag HOC Terminal into Applications. The first time, right-click the app → *Open* → *Open*.

The app opens the live terminal, so updates arrive on their own. Sign in with Whop or Discord as on the website.

## Releasing a new version
Actions → **Release** → Run workflow → enter the version (e.g. `1.0.1`). Windows and Mac installers are built and published as a release; the Downloads page in the terminal picks up the newest release automatically.
